## Dashboards & Tools

Free, read-only analytics we build and maintain for the networks we validate.

| Tool | What it's for |
|---|---|
| 🟣 **[Celestia Economic Dashboard](https://skyneticlabs.com/celestia)** | Staking yield, inflation schedule, data-availability costs, stake concentration, self-bond, trends and correlations |
| 🔎 **[Celestia Validator & Fund Lookup](https://skyneticlabs.com/celestia/lookup/)** | Foundation Delegation Program seats, seat-holder uptime and archived cohorts |
| 🔌 **[Celestia Public API](https://skyneticlabs.com/celestia/api/v1/)** | Open JSON API (no auth, open CORS): network state, economics, validators, DA cost per namespace |
| 🟪 **[Monad Economics Terminal](https://skyneticlabs.com/monad)** | Transfer cost, block headroom, fee predictability, stake distribution and top validators |
| 📚 **[Node Operator Guides](https://skyneticlabs.gitbook.io/docs/)** | Installation, upgrades, useful commands, TMKMS / Horcrux, monitoring setup |

## What We Provide

### Infrastructure
- **Own bare-metal hardware** in Buenos Aires — AMD EPYC (32 cores), 192 GB ECC, 16 TB NVMe on ZFS, 10–100 Gbps uplink.
- **Protected keys** — remote signer and sentry nodes; signing keys never live on internet-facing machines.
- **Always watched** — 24/7 metrics, alerting and on-call; upgrades tested on testnet before mainnet; off-site backups.

### Documentation
- **Setup guides**, **upgrade instructions** and **useful commands** for every network we run.
- Security-first validator design: **sentry topology**, **TMKMS / Horcrux** remote signing and **automated failover**.
- Operator-side **security checklists** — see the [Celestia](Celestia.md) and [Monad](Monad.md) pages.

### Community & Contribution
- Maintaining reliable validator infrastructure across multiple chains.
- Publishing open dashboards, APIs and tooling for the ecosystems we support.
- Adding geographic diversity: most validators run in Europe and North America — Latin America hosts **under 1%**.
